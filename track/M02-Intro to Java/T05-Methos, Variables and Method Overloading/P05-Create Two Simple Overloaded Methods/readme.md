Create Two Simple Overloaded Methods

Create a class named Printer with two methods that have the same name:
void show(int number)
void show(String word)

The first method must print a number. The second method must print a word.

In main():
1. Read one integer.
2. Read one word.
3. Create one Printer object.
4. Call both show() methods.

Do not print input prompts.

Input
<number>
<word>

Output
Number: <number>
Word: <word>

Sample Input
7
Java

Sample Output
Number: 7
Word: Java
