### Use the Four Simple Method Types

Create a class named MethodDemo with these four simple methods:

| Method | What it does |
| :--- | :--- |
| sayHello() | Prints Hello from a method! |
| greet(String name) | Prints Hello, <name>! |
| getLuckyNumber() | Returns 7 |
| add(int first, int second) | Returns the sum of two numbers |

In main():
1. Read a name.
2. Read two integers.
3. Create one MethodDemo object.
4. Call all four methods.
5. Print the returned lucky number and sum.

Do not print input prompts.

#### Input
<name>
<first number>
<second number>

#### Output
Hello from a method!
Hello, <name>!
Lucky Number: 7
Sum: <sum>

#### Sample Input
Maya
4
6

#### Sample Output
Hello from a method!
Hello, Maya!
Lucky Number: 7
Sum: 10
