Student Methods Final Challenge

Create a class named Student with:
- A String instance variable named name
- A method setName(String name) that uses this.name = name
- A method showName() that prints the stored name
- Two overloaded showScore() methods:
  void showScore(int first)
  void showScore(int first, int second)

The first overloaded method must print one score. The second must print the total of two scores.

In main():
1. Read the student's full name.
2. Read two integer scores.
3. Create one Student object.
4. Store and print the name.
5. Call both showScore() methods.

Do not print input prompts.

Input
<student name>
<first score>
<second score>

Output
Student Name: <student name>
First Score: <first score>
Two-Score Total: <total>

Sample Input
Asha Rao
70
80

Sample Output
Student Name: Asha Rao
First Score: 70
Two-Score Total: 150
