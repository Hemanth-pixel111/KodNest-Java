# Store a Name Using this

Create a class named Student with:
- A String instance variable named name
- A method setName(String name)
- A method displayName()

Inside setName(String name), use:
```java
this.name = name;
```

In main():
1. Create one Student object.
2. Read a name.
3. Call setName() to store the name.
4. Call displayName() to print it.

No input prompts.

### Input
<name>

### Output
Student Name: <stored name>

### Sample Input
Riya

### Sample Output
Student Name: Riya
