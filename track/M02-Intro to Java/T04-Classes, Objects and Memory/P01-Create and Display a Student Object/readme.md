### Create and Display a Student Object

Create a complete Java program that reads one student's details, stores them inside one Student object, and displays the stored details.

#### Class and fields
| Field Name | Data Type |
| :--- | :--- |
| id | int |
| name | String |
| course | String |
| javaScore | double |

#### Input Format
Read the following values in this exact order:
1. Student ID
2. Student name
3. Course name
4. Java score

The name and course are single words without spaces.

#### Output Format
Print exactly five lines:
Student Profile
ID: <id>
Name: <name>
Course: <course>
Java Score: <javaScore>

#### Sample Input
101
Asha
Java
84.5

#### Sample Output
Student Profile
ID: 101
Name: Asha
Course: Java
Java Score: 84.5
