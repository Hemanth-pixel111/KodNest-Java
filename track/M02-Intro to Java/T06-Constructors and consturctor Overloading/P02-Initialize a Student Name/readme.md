### Initialize a Student Name

Use the provided Student class.

Complete the constructor Student(String name) so that it stores the received name in the instance variable using:

`this.name = name;`

The display() method is already provided. In main(), read one full name, create one Student object and call display().

Do not print input prompts.

#### **Input**
`<student name>`

#### **Output**
`Student Name: <student name>`

#### **1 ) Sample Input**
`Asha Rao`

#### **Sample Output**
`Student Name: Asha Rao`
