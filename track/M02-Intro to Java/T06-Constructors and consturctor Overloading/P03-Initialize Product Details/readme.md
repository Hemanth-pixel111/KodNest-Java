### Initialize Product Details

Use the provided Product class.

Complete the parameterized constructor Product(String name, double price). Store both received values in the matching instance variables using this.

The display() method is already provided. In main(), read the product name and price, create one Product object and call display().

Do not print input prompts.

#### **Input**
`<product name>`
`<price>`

#### **Output**
`Product: <product name>`
`Price: <price>`

#### **1 ) Sample Input**
`Notebook`
`45.5`

#### **Sample Output**
`Product: Notebook`
`Price: 45.5`
